# 우리가족 대시보드

가족용 체크리스트 대시보드입니다. `index.html` 파일 하나로 동작하며, 인터넷 없이 열어도 그대로 쓸 수 있습니다.

- 화면: 오늘의 루틴 · 도마뱀 밥 주기 · 용돈 통장 · 가족 랜덤 미션 · 공부 타이머 · 한줄 톡 · 주말 수업 횟수 · 장보기/메모
- 사용법: 아래 주소를 열거나, 휴대폰 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 열립니다.
  - https://sn2327-afk.github.io/family-dashboard/
- 기록 저장: 각 기기의 브라우저(localStorage)에 저장됩니다. 기기끼리 자동으로 동기화되지 않습니다.
