# 우리가족 대시보드

가족용 체크리스트 대시보드입니다. `index.html` 파일 하나로 동작하고, 인터넷이 없어도 열립니다.

- 주소: https://sn2327-afk.github.io/family-dashboard/
- 화면: **상단 분류 폴더**(오늘 루틴 · 코인상점 · 포켓몬 도감 · 도마뱀·수업 · 메모·톡 · 전체) · 도마뱀 밥 주기 · 은우/다윤 루틴 · 용돈 통장 · 코인 지갑/먹거리 상점 · 포켓몬 도감 · 가족 랜덤 미션 · 우리집 한줄 톡 · 주말 수업 횟수 · 장보기/가족 메모 · 오늘의 저녁 메뉴
- 그림: 히어로 '우리 집' · 도마뱀 · 은우/다윤 얼굴은 동글동글 파스텔 치비 일러스트(base64 인라인). 파일 하나로 열려도 그림이 그대로 보입니다.
- 공부 타이머·태블릿 종료 기능은 2026-11-16 새남 님 요청으로 화면에서 뺐습니다. (기기에 남아 있던 `timer` 값은 읽지 않고 그냥 무시합니다)

## 은우 루틴 규칙

- `은우 숙제`는 **화요일·금요일**에만 오늘 할 일에 나옵니다. 다른 요일에는 목록·진행률 모수·주간 칸 계산에서 빠지고, 카드 안에 `🗓️ 은우 숙제는 화·금요일` 안내가 뜹니다.
- 요일 규칙은 할 일 데이터의 `days` 값(0=일 … 6=토)으로 정해지고, 기본 할 일(`eunwoo-homework`)은 앱이 항상 화·금으로 되돌립니다. 직접 추가한 할 일은 예전처럼 요일 제한이 없습니다.
- `다윤 숙제` 옆 `🌙 오늘 숙제 없는 날로 표시` 버튼을 누르면 그날 다윤 숙제가 **면제**됩니다. 숙제 줄은 흐려지고 `면제` 뱃지가 붙으며, 오늘의 루틴 달성률 모수와 다윤 주간 달력에서 빠져 인강만 해도 100%가 됩니다. 다시 누르면 해제되고, 켤 때 이미 체크돼 있던 숙제는 풀립니다.
- 숙제 없는 날 값은 `state.days["YYYY-MM-DD"].noHomework.dayun = true` 로 저장되어 가족 모든 기기에 실시간으로 함께 보입니다.
- 금요일 받아쓰기 점수: 은우 카드 안 `📝 금요일 받아쓰기 점수` 칸에 0~100점을 저장합니다. 주 단위로 저장되어(`state.dictation.scores["YYYY-MM-DD(금)"] = 점수`) 최근 기록 칩을 눌러 지난 주 점수도 고칠 수 있고, 금요일 당일에는 `오늘 받아쓰기 날!` 뱃지가 뜨고, 다른 기기에도 실시간으로 공유됩니다.

## 상단 분류 폴더 (2026-11-20 추가)

- 헤더 바로 아래에 폴더 탭이 붙어 있습니다(`🏠 오늘 루틴` · `🎁 코인상점` · `📖 포켓몬 도감` · `🦎 도마뱀·수업` · `📝 메모·톡` · `📋 전체`). 누르면 그 분류 카드만 보여서 아래로 길게 내려가지 않아도 됩니다. 스크롤해도 위에 붙어 있습니다(가로 스크롤 칩).
- 폴더는 카드를 숨기기만 하고 화면에서 없애지 않습니다 → 폴더를 오가도 입력 중이던 값·체크 상태·실시간 동기화가 그대로 유지됩니다.
- 마지막으로 고른 폴더는 이 기기에 기억됩니다(`localStorage.familyDashboard.folder.v1`). `📋 전체`에서는 백업·초기화가 있는 푸터까지 보입니다.
- 기존 하단 탭바는 상단 폴더와 겹쳐서 없앴습니다.

## 코인 지갑 · 먹거리 보상 상점 (2026-11-19 추가 · 11-20 소민 지갑 추가)

- 은우·다윤·소민(아빠)이 각각 `🪙 코인` 잔액을 가집니다. 아이 카드 머리 아래 코인 줄(은우·다윤)과 상점 지갑 카드(3명)에서 `−1 / +1 / +5`로 바로 조절합니다.
- 소민은 루틴 카드가 없는 지갑 전용 멤버입니다. 예전 기록에 `somin` 키가 없으면 0개로 조용히 채워집니다.
- `🎁 먹거리 보상 상점` 섹션에서도 지갑을 고르고 `−1 / +1 / +5`, `직접 조절(넣기/빼기)`을 쓸 수 있습니다.
- **자동 적립은 없습니다.** 루틴 체크·미션으로는 코인이 쌓이지 않고, 부모가 직접 줄 때만 늘어납니다.
- 기본 보상: 🍦 아이스크림/편의점 간식 5 · 🍡 탕후루/떡볶이 10 · 🍲 마라탕 20 · 🍗 치킨 25 · 🍕 피자 30 코인.
- `교환하기` → 지갑을 고른 뒤 누르면 코인이 차감되고 `교환 내역`에 누가·언제·무엇을·몇 코인인지 남습니다. `전달 완료` 체크와 삭제가 됩니다.
- `⚙️ 보상 메뉴 관리`에서 보상 추가(이름+코인)·코인 수 수정·삭제가 됩니다.
- 저장 위치: `state.coins`(잔액·조절 기록), `state.shop`(메뉴·교환 내역). 예전 기록에 이 값이 없으면 기본값으로 조용히 채워집니다.

## 실시간 동기화

- 엄마·아빠·은우·다윤 폰이 같은 기록을 함께 봅니다. 한 기기에서 체크하면 다른 기기에 몇 초 안에 나타납니다.
- 저장소: Firebase Realtime Database (`rooms/saenam-family-2026/state`)
  - 읽기/쓰기: REST `GET`/`PUT` + `EventSource`(SSE) 실시간 스트림
  - 스트림이 끊기면 4초마다, 붙어 있으면 20초마다 안전망 확인
- 화면 위쪽 뱃지: `☁️ 실시간 공유 중` / `🔄 저장 중…` / `⚠️ 오프라인` (눌러서 새로고침)
- 인터넷이 끊겨도 이 기기(localStorage)에는 저장되고, 다시 연결되면 자동으로 맞춰집니다.
- 기기별로 따로 두는 값: 보고 있는 탭, 한줄 톡에 쓸 내 이름
- 처음 접속할 때 서버에 기록이 있으면 서버 기록을 쓰고, 서버가 완전히 비어 있을 때만 이 기기 기록을 올립니다.
- 새로고침 후에도 변경분을 계속 올릴 수 있도록, 서버의 마지막 기록이 이 기기에서 올라온 경우에도 비교 기준(`shadow`)을 서버 상태로 맞춥니다.

## 배포

```bash
bash tmp/deploy_sync.sh   # 빌드 → index.html(robots noindex) → git push
```

- 빌드 원본: `tmp/template.html`(화면) + `tmp/app.js`(동작) → `python3 tmp/build.py 우리가족_대시보드.html`
- 검증: `sh tmp/pw.sh tmp/e2e_pokemon.py` (포켓몬 도감·3지갑·폴더 탭 E2E 41항목, 모의 Firebase), `sh tmp/pw.sh tmp/shop_e2e.py` (코인·상점 E2E, 모의 Firebase로 실제 DB는 건드리지 않음), `sh tmp/pw.sh tmp/check_live_shop.py` (라이브 화면 확인, 읽기만), `python3 tmp/sync_e2e.py [URL]` (두 기기 실시간 동기화 E2E), `python3 tmp/sync_offline.py` (오프라인 복귀), `sh tmp/pw.sh tmp/test_eunwoo.py` (은우 숙제 요일·받아쓰기 점수, 모의 Firebase로 실제 DB는 건드리지 않음), `sh tmp/pw.sh tmp/check_live.py` (라이브 확인, 읽기만)
- 초기 상태로 되돌리기: `python3 tmp/reset_and_shot.py`
