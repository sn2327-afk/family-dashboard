# 우리가족 대시보드

가족용 체크리스트 대시보드입니다. `index.html` 파일 하나로 동작하고, 인터넷이 없어도 열립니다.

- 주소: https://sn2327-afk.github.io/family-dashboard/
- 화면: **상단 분류 폴더**(오늘 루틴 · 코인상점 · 포켓몬 도감 · 도마뱀·수업 · 메모·톡 · 전체) · 도마뱀 밥 주기(**🦎 오늘 밥 준 사람 +1코인** — 아빠(소민)·은우·다윤 각각 체크) · 은우/다윤 루틴(**👕 빨래 개기 +1코인** · 은우 **💯 받아쓰기 100점 +1코인** · 은우 **📚 주말 숙제 +1코인** · **🏆 일주일 완료 +2코인**(은우·다윤)) · 코인 지갑/먹거리 상점(**엄마 전용 잠금**) · 포켓몬 도감 · 가족 랜덤 미션 · 우리집 한줄 톡 · 주말 수업 횟수 · 장보기/가족 메모 · 오늘의 저녁 메뉴
- 그림: 맨 위 히어로 사진은 새남 님이 보내 주신 크레파스 가족 그림(`우리가족 ♡ 행복해 ♡`, 2026-11-23 교체)을 600×600 WebP로 줄여 base64 인라인으로 넣었습니다 — 정사각형 그대로 잘리지 않게 표시합니다. 도마뱀·은우/다윤 얼굴은 동글동글 파스텔 치비 일러스트(base64 인라인). 파일 하나로 열려도 그림이 그대로 보입니다.
- 공부 타이머·태블릿 종료 기능은 2026-11-16 새남 님 요청으로 화면에서 뺐습니다. (기기에 남아 있던 `timer` 값은 읽지 않고 그냥 무시합니다)

## 은우 루틴 규칙

- **은우의 100원 용돈 통장은 2026-11-23에 없앴습니다.** 카드 위 `용돈 0원` 배지와 `용돈 통장` 카드, 할 일 체크당 100원 적립 계산과 정산 버튼을 모두 빼고, 두 아이 모두 `🪙 코인` 지갑 하나로 통일했습니다(옛 용돈 기록은 지우지 않고 읽지도 않습니다).
- `은우 숙제`는 **화요일·금요일**에만 오늘 할 일에 나옵니다. 다른 요일에는 목록·진행률 모수·주간 칸 계산에서 빠지고, 카드 안에 `🗓️ 은우 숙제는 화·금요일` 안내가 뜹니다.
- 요일 규칙은 할 일 데이터의 `days` 값(0=일 … 6=토)으로 정해지고, 기본 할 일(`eunwoo-homework`)은 앱이 항상 화·금으로 되돌립니다. 직접 추가한 할 일은 예전처럼 요일 제한이 없습니다.
- `다윤 숙제` 옆 `🌙 오늘 숙제 없는 날로 표시` 버튼을 누르면 그날 다윤 숙제가 **면제**됩니다. 숙제 줄은 흐려지고 `면제` 뱃지가 붙으며, 오늘의 루틴 달성률 모수와 다윤 주간 달력에서 빠져 인강만 해도 100%가 됩니다. 다시 누르면 해제되고, 켤 때 이미 체크돼 있던 숙제는 풀립니다.
- 숙제 없는 날 값은 `state.days["YYYY-MM-DD"].noHomework.dayun = true` 로 저장되어 가족 모든 기기에 실시간으로 함께 보입니다.
- 금요일 받아쓰기 점수: 은우 카드 안 `📝 금요일 받아쓰기 점수` 칸에 0~100점을 저장합니다. 주 단위로 저장되어(`state.dictation.scores["YYYY-MM-DD(금)"] = 점수`) 최근 기록 칩을 눌러 지난 주 점수도 고칠 수 있고, 금요일 당일에는 `오늘 받아쓰기 날!` 뱃지가 뜨고, 다른 기기에도 실시간으로 공유됩니다. **100점을 저장하면 그 주 1코인이 자동으로 붙습니다**(아래 `💯 받아쓰기 100점 (+1코인)` 항목).

## 상단 분류 폴더 (2026-11-20 추가)

- **처음 열면 `📋 전체`**가 선택되어 모든 카드가 한눈에 보이고, 그다음에 하위 분류를 눌러 하나씩 봅니다. (11-20 순서·기본값 변경)
- 폴더는 카드를 숨기기만 하고 화면에서 없애지 않습니다 → 폴더를 오가도 입력 중이던 값·체크 상태·실시간 동기화가 그대로 유지됩니다.
- 마지막으로 고른 폴더는 이 기기에 기억됩니다(`localStorage.familyDashboard.folder.v2`). 키를 v2로 올려서, 예전에 `today`로 저장돼 있던 기기도 이번 업데이트 뒤 처음 열 때는 `전체`가 먼저 보입니다. `📋 전체`에서는 백업·초기화가 있는 푸터까지 보입니다.
- 기존 하단 탭바는 상단 폴더와 겹쳐서 없앴습니다.

## 코인 지갑 · 먹거리 보상 상점 (2026-11-19 추가 · 11-20 소민 지갑 추가)

- 은우·다윤·소민(아빠)이 각각 `🪙 코인` 잔액을 가집니다. 아이 카드 머리 아래 코인 줄(은우·다윤)과 상점 지갑 카드(3명)에서 `−1 / +1 / +5`로 바로 조절합니다.
- 소민은 루틴 카드가 없는 지갑 전용 멤버입니다. 예전 기록에 `somin` 키가 없으면 0개로 조용히 채워집니다.
- `🎁 먹거리 보상 상점` 섹션에서도 지갑을 고르고 `−1 / +1 / +5`, `직접 조절(넣기/빼기)`을 쓸 수 있습니다.
- **자동 적립은 거의 없습니다.** 루틴 체크·미션으로는 코인이 쌓이지 않고, 부모가 직접 줄 때만 늘어납니다. (예외: `👕 빨래 개기`는 아이가 직접 눌러 하루 1개, `💯 받아쓰기 100점`은 그 주 1개, `📚 은우 주말 숙제`는 주말 1개, `🏆 일주일 완료`(은우·다윤)는 그 주 2개, `🦎 오늘 밥 준 사람`은 밥 준 사람이 직접 눌러 사람마다 하루 1개 — 아래 항목 참고)
- 기본 보상: 🍦 아이스크림/편의점 간식 5 · 🌶️ 떡볶이 10 · 🍲 마라탕 20 · 🍗 치킨 25 · 🍕 피자 30 코인. (11-20 탕후루 제외 · 예전 저장 기록의 `탕후루 / 떡볶이`는 불러올 때 `떡볶이`로 옮겨 적습니다)
- 상점 위 `누구 코인으로 교환할까요?` 칩(👦 은우 · 👧 다윤 · 👨 소민)에서 교환할 사람을 크게 고릅니다. 칩에는 그 사람의 지금 코인 수가 같이 보이고, 고른 사람 기준으로 `교환하기`가 동작합니다. (지갑 카드를 눌러도 같은 방식으로 선택됩니다)
- `교환하기` → 누르면 그 사람 코인이 차감되고 `교환 내역`에 누가·언제·무엇을·몇 코인인지 남습니다. `전달 완료` 체크와 삭제가 됩니다.
- `⚙️ 상점 메뉴·코인 개수 설정`(엄마 모드에서만 보이는 크림색 버튼)을 펼치면 보상 추가(이름+코인)·코인 수 수정·삭제가 됩니다.
- 저장 위치: `state.coins`(잔액·조절 기록), `state.shop`(메뉴·교환 내역), `state.lock`(엄마 모드 비밀번호 해시). 예전 기록에 이 값이 없으면 기본값으로 조용히 채워집니다.

## 엄마 전용 코인 잠금 (2026-11-20 추가)

- 페이지를 열면 엄마 모드는 **기본 잠김**입니다. 잠긴 동안에는 누구나 코인 잔액 확인 · `교환하기` · 교환 내역 보기를 할 수 있고, **코인 조절(`−1/+1/+5`, 직접 넣기·빼기) · `⚙️ 보상 메뉴 관리` · 교환 내역 삭제**는 감춰집니다(아이 카드 코인 줄의 `−1/+1/+5`도 숨김, 자물쇠 버튼만 표시).
- 상점 위 `🔒 엄마만 코인 올리기`(또는 아이 카드 코인 줄의 `🔒 엄마만`, 헤더의 `🔒 엄마 모드`)를 누르면 4자리 비밀번호 창이 열립니다. 기본 비밀번호는 **`0203`**이고, 틀리면 안내 문구와 함께 창이 흔들리며 잠금이 유지됩니다.
- `0203`으로 열면 `🔓 엄마 모드 열림`이 되고 코인 조절·`⚙️ 상점 메뉴·코인 개수 설정`·교환 내역 삭제가 모두 살아납니다. 상점 위 `🔒 잠그기`(헤더의 `🔒 잠그기`도 같음)를 누르면 즉시 다시 잠깁니다.
- 창 안 `이 기기 잠금 해제 유지`를 켜고 열면 그 기기는 새로고침해도 열린 채로 쓰고(`localStorage.familyDashboard.lockKeep.v1`), 끄고 열면 새로 열 때 다시 잠깁니다. `🔒 잠그기`를 누르면 유지 설정도 함께 꺼집니다.
- 엄마 모드에서 `비밀번호 변경`으로 4자리 비밀번호를 바꿀 수 있습니다. 바꾼 비밀번호는 가족 모든 기기에 함께 저장됩니다(해시로만 저장하고, 화면·기록에는 번호를 남기지 않습니다).
- 잠금은 가족끼리 아이가 코인을 마음대로 올리지 못하게 하는 **화면 잠금**입니다. 서버 쪽 권한 검사가 아니라 브라우저 안에서 확인하므로, 마음먹고 코드를 뜯어보는 사람까지 막는 보안 장치는 아닙니다.

## 🦎 도마뱀 밥 준 사람 (+1코인 · 사람마다 따로 체크) (2026-11-23 추가)

- `도마뱀 밥 주기` 카드 안, `마지막 밥 준 날`·`다음 밥 주는 날` 아래에 **`🦎 오늘 밥 준 사람 (+1코인)`** 칸이 있습니다. 버튼은 **`👨 아빠(소민)` · `👦 은우` · `👧 다윤`** 세 개이고, **각각 따로 체크**됩니다 — 한 사람을 눌러도 다른 사람 체크는 그대로 남습니다(예: 은우가 누르고 다윤이 이어서 누르면 둘 다 체크되고 각각 +1코인).
- 버튼을 누르면 **급여 완료 처리 + 3일 주기 갱신(`state.geo.lastFeed` = 오늘) + 그 사람 코인 +1**(`state.coins.balances` · `state.coins.earned`)이 한 번에 됩니다. 코인 기록에는 `도마뱀 밥 주기 (+1)` 한 줄이 남습니다.
- **사람마다 하루 1번**입니다. 같은 사람을 다시 누르면 **그 사람만** 체크가 풀리고 그날 받은 1코인·코인 기록만 회수됩니다(다른 사람 코인은 그대로, 잔액 0 미만·누적 획득 아래로 내려가지 않음). 연타해도 사람마다 하루 1개를 넘지 않습니다.
- **한 명이라도 체크되어 있으면** 오늘 밥을 준 것으로 기록되고(진행률·도감 `밥 준 날`에 반영, 3일 주기 갱신), **세 명 모두 풀려 0명이 되면** 오늘 급여 기록도 취소되어 직전 급여일(`prevFeed`)로 돌아갑니다.
- **엄마 모드(`0203`) 잠금과 무관**하게 아빠·은우·다윤 누구나 직접 누를 수 있습니다(빨래 개기·받아쓰기·주말 숙제와 같음). 수동 코인 조절은 예전처럼 `0203`에서만 됩니다.
- 엄마가 줬을 때처럼 **코인 없이 급여만 기록**하려면 카드 위 `🍽️ 도마뱀 밥 주기` 체크 줄을 누르면 됩니다. 그 체크 줄을 풀면 오늘 체크된 사람들의 코인도 함께 회수됩니다.
- 저장 위치: `state.geo.rewards["YYYY-MM-DD"] = { somin: 코인기록id|'', eunwoo: …, dayun: … }` — 키가 있으면 그 사람이 준 것이고, 값은 그날 남긴 코인 기록 id입니다(코인이 가득 차 못 주면 `''`). 예전 한 명짜리 기록(`{ who, rewardId }`)도 읽을 때 이 맵으로 옮겨 옵니다.

## 👕 빨래 개기 (+1코인) (2026-11-21 추가)

- **은우·다윤 카드에만** 코인 줄 바로 아래 `👕 빨래 개기 (+1코인)` 줄이 있습니다. 소민(아빠)에게는 없습니다.
- **아이들이 직접 누릅니다.** 엄마 모드(`0203`)가 잠겨 있어도 이 줄은 그대로 보이고 눌립니다. 나머지 수동 조절(`−1/+1/+5`, 직접 조절, 상점 메뉴 설정)은 예전처럼 `0203` 잠금이 유지됩니다.
- 누르면 그 아이 코인이 **+1**(`state.coins.balances`), 포켓몬 진화에 쓰는 **누적 획득도 +1**(`state.coins.earned`), 코인 기록에 `빨래 개기 (+1)` 한 줄이 남습니다.
- **하루 1번만 됩니다.** 한 번 누른 뒤 다시 누르면 완료가 취소되고 그날 받은 1개만 회수됩니다(잔액이 0 아래로 내려가지 않음). 연타해도 하루에 1개를 넘지 않습니다.
- 자정이 지나면 새 날로 다시 미체크 상태가 됩니다. 어제 체크는 어제 기록으로 남고 오늘 코인을 만들지 않습니다.
- 루틴 달성률·주간 달력과는 **분리**되어 있어, 빨래 개기를 눌러도 진행률은 변하지 않습니다.
- 저장 위치: `state.days["YYYY-MM-DD"].laundry = { eunwoo: '코인기록id', dayun: '코인기록id' }` (값은 그날 남긴 코인 기록 id라서 취소할 때 그 줄만 지웁니다).

## 💯 받아쓰기 100점 (+1코인) (2026-11-21 추가)

- 은우 카드의 `📝 금요일 받아쓰기 점수` 칸에 **`100`을 넣고 저장하면 그 주 코인이 +1** 붙습니다(`state.coins.balances.eunwoo` + `state.coins.earned.eunwoo`). 코인 기록에는 `받아쓰기 100점 (+1)` 한 줄이 남습니다.

## 실시간 동기화

- 엄마·아빠·은우·다윤 폰이 같은 기록을 함께 봅니다. 한 기기에서 체크하면 다른 기기에 몇 초 안에 나타납니다.
- 저장소: Firebase Realtime Database (`rooms/saenam-family-2026/state`)
  - 읽기/쓰기: REST `GET`/`PUT` + `EventSource`(SSE) 실시간 스트림
  - 스트림이 끊기면 4초마다, 붙어 있으면 20초마다 안전망 확인
